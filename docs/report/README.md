# ESP32 BME280 MQTT — Project Report

This directory contains the academic report for an
Internet of Things laboratory project completed at
Berliner Hochschule für Technik (BHT) in 2026.

**Authors:** Mazen Younis · Mert Satici

**Course:** Internet of Things

## Project Report

[ESP32 Sensor Data Acquisition and MQTT Communication](IoT_Labor2_Public_Redacted.pdf)

The report documents:

- ESP32-WROVER-DEV development
- BME280 environmental sensor integration
- I²C communication
- Temperature, humidity and pressure measurements
- Wi-Fi connectivity
- MQTT communication and JSON telemetry
- Original hardware testing and experimental results

## Publication Notes

The publicly shared report has been redacted to protect
student identification numbers and private network details.

The report documents the original university experiments.

The C implementation published in this portfolio repository
contains subsequent improvements and has not been independently
rebuilt or retested on ESP32 hardware.
